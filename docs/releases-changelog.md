## Kira HRT 2.3.0  (`v2.3.0`)
*发布: 2026-10-26T20:56Z  |  prerelease=false  |  draft=false*

# Kira HRT 2.3.0

自 2.2.2 以来的全部变化。这一版的重点是校准的可信度：曲线现在知道自己用了哪些化验、有没有背景浓度，也会明确告诉你哪些数据没有参与拟合。

## 校准与 PK

- 新增「估计背景 E2」：给药前的雌二醇化验用于估计内源性背景（取中位数），拟合时扣除、最终曲线只加一次。没有背景化验时偏移为 0，曲线与 2.2.2 逐点一致。
- 校准页分别显示给药后的拟合点数与背景点数；只有背景化验、没有给药后化验时，明确标注「未完成药代参数拟合」。
- 没有任何化验时，Transmtf 校准不再乘上一个凭空的系数（此前实测 1.13–6.39×）；一条睾酮化验也不会再被当作 500 pg/mL 的雌二醇进入拟合。
- 前向（forward）校准的滤波器配置不再取决于未来化验的条数。此前新增第 3 条化验会改写更早的历史曲线（实测最大差 6.55%）。
- 贴片：同一时刻记录的「取下」按零佩戴处理；修复短贴片把长贴片的曲线剪成 0 的问题。混合定向 / 无向移除的配对现在在界面、内置引擎与 Transmtf 引擎之间一致。
- 没有血检时曲线仍只是模型估计。首页「添加血检以校准」提示已注明这一点。

## 化验类型

- 化验记录新增激素类型：`E2`、`T`、未确认。
- 旧记录若没有类型，会保留但标为「未确认」，不再根据单位猜测。未确认的化验排除在所有校准（E2、T、背景）之外，界面显示其数量，直到你确认类型。

## 导入与导出

- 导入界面新增「旧版本兼容」开关：勾选后按单位还原旧备份里的 E2 / T 类型；旧备份默认勾选，可取消。
- 重写《数据导入导出适配规范》，补齐 `analyte` 字段与旧格式的映射说明。
- Featherline 导入保留其自带的分析物类型；CSV 与 PDF 对未确认类型显示 Unknown。

## 图表

- 新增 3 天 / 30 天 / 全部范围切换；纵轴可上下拖动缩放（本次会话内保持）。
- 长历史按峰谷抽稀，多年视图的滚动与点按不再卡顿；时间轴可以拖动查看任意时刻。3 天范围显示每次给药的标记。

## 提醒与用药方案

- 用药方案直接显示「下一次」「下下次」的提醒时间，编辑时实时预览。
- 修复编辑旧方案时关闭动画直接闪没。
- Android 修改用药方案后立即重排本机通知队列。
- 网页端提醒只在页面可见时轮询，与 Android 的系统通知互不重复。

## 隐私与 MCP

- MCP 不再提供整份导出（移除 `hrt_sync_state`）；原始用药记录只暴露最近 7 天，化验、日志等读取照旧。
- `hrt_add_lab_result` 可以传 `analyte`；`hrt_predict_levels` 返回拟合点数、背景点数、未确认点数与背景浓度。

## 界面

- 直接访问 `/about`（无尾斜杠）不再丢失脚本与图片。
- 账户页去掉重复的标题卡片，页脚新增 Status 入口；设置页在不可用的设备上不再显示应用锁提示。
- 舌下给药只保留预设档位，旧的自定义含服记录按最接近的档位读取。

## 下载

- `KiraHRT-2.3.0-release.apk` — 标准包（含 FCM 补充推送与应用内更新），SHA-256 `603ABE9E484E8D835004FE2BAD6AF7ACA8BEB80CE0CA3D490CAB19D3A7A24BC2`
- `KiraHRT-2.3.0-fdroid.apk` — F-Droid 包（无 FCM、无自更新），SHA-256 `422AF9A0533F4403ECF9D82F1488CB2295B0A7B71FDA41274003E4EF4F8E1A0C`

- 安全：分享链接只包含必要字段；退出登录清空浏览器缓存的提醒文案与去重记录。

- 方案：修复空用药方案把云端方案清空的问题；同步失败都有明确错误码。
- 修复：备份导入某一项过大而失败时，不再留下已替换的数据与删除标记；重复合并导入不再重复；高版本备份明确拒绝。

标准版包含 FCM 补推和应用内更新；F-Droid 版不含 Firebase 和应用内更新。两个包使用原有签名，版本号 2.2.2 / 2002002。

## Kira HRT 2.1.0  (`v2.1.0`)
*发布: 2026-10-23T04:48:46Z  |  prerelease=false  |  draft=false*

## 2.1.0 — 安全审计修复版

本次把 2026-10-23 安全审计的 16 项（2 High / 8 Medium / 6 Low）全部修完，并修了两个界面问题。

### 安全

- **密钥轮换**：修改密码或绑定凭据时，曾把记录密钥 R（= DEK ⊕ H）当成 DEK 包进口令信封，导致该账号此后**永远无法轮换密钥**。现在包裹裸 DEK；2.0.4 已中招的账号会在下次改密码时自动修复。
- **用药方案按账号隔离**：方案原先全局保存，共用设备上后一个账号会看到、并沿用前一个账号的方案与提醒，还会把它推进自己的云端。现在按账号分键，首次登录自动迁移旧数据。
- **内容安全策略（CSP）**：Web 与 App 均启用；首屏主题脚本改为 `/theme-init.js`，Service Worker 注册改为 `/registerSW.js`。
- **分享链接**：创建失败时不再静默改存明文。
- **限流**：客户端 IP 改读 `CF-Connecting-IP` / 代理追加的最后一跳；OAuth `start` 增加限流并清理过期 state。
