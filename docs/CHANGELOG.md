## 1.0.x

### 1.0.1 · 2026-09-27

**新增**

- 应用内检查新版本；「设置 → 关于」提供手动检查入口。
- 每日用药提醒，可设置多个药物与提醒时间。
- X、Google 登录后自动回跳。
- 外部网页改用系统浏览器打开。
- 启动画面与 Android 系统栏适配。
- 本机健康记录使用加密存储。

### 1.0.2 · 2026-10-06

**新增**

- K 线模式：三栏终端布局（图表 / 近期剂量 / 记录）。
- K 线按区间自动切换粒度：7 天 4 小时 K、30 天日 K、超过 120 天周 K。
- K 线红跌绿涨，悬停显示开 / 高 / 低 / 收；未来只保留两格。
- 个性化设置：曲线样式、方格图、像素试管，随账户同步。
- 点订单可一键再次记录，速记默认当前时间。
- 登录设备列表：类型图标 + 设备型号 + 当前设备绿钩。
- 用药提醒改用应用内时间选择器。

**改进**

- 关闭方格图时浓度图自动加长。
- 账户页使用本地缓存，不再闪烁。
- 安装包从 48MB 降到 17MB（OCR 改为按需下载）。
- 背景音乐压缩约六成。

**修复**

- 多设备同步分页漏记录。

### 1.0.3 · 2026-10-08

**新增**

- Android 返回手势适配：侧滑逐级退出——先关弹窗、再退子页面、最后回主页。

- 所有外链统一由系统默认浏览器承载，不再占用应用内页面。

**改进**

- K 线「近期剂量」深度条改为跟随主题主色，并移除行悬浮变色。

**修复**

## 2.1.x

### 2.1.0 · 2026-10-23

安全审计修复（2 High / 8 Medium / 6 Low，共 16 项）。

**安全**

- 密钥轮换：修改密码或绑定凭据时曾把记录密钥 R（= DEK ⊕ H）当成 DEK 包进口令信封，导致账号此后无法轮换密钥；现包裹裸 DEK，2.0.4 已受影响的账号在下次改密码时自动修复。
- 用药方案按账号隔离：此前全局保存，共用设备上会串号并推进自己的云端；现按账号分键，首次登录自动迁移旧数据。
- 内容安全策略（CSP）：Web 与 App 均启用；首屏主题脚本改为 `/theme-init.js`，Service Worker 注册改为 `/registerSW.js`。
- 分享链接创建失败时不再静默改存明文。
- 限流：客户端 IP 改读 `CF-Connecting-IP` / 代理追加的最后一跳；OAuth `start` 增加限流并清理过期 state。
- 推送：一个设备令牌只属于一个账号；改密码会注销该账号的全部设备令牌；推送载荷不再包含药名与剂量，文案由设备按本机方案生成。
- 离线存储：非 JSON 的旧明文（会话令牌、枚举值）正确迁移加密，不再被当成损坏丢弃。
- 新增「退出并清除本机数据」。
- 更新包下载时校验 SHA-256，不匹配拒绝安装；新增指纹会作废应用锁密钥，并给出恢复路径。

**修复**

- 新增用药的时间选择器与方案、检查记录统一：分钟以 1 递增，数字可直接输入。
- 用药方案「新增」面板打开后，侧边返回一次只关闭该面板。

**验证**

- 服务端 205 个测试全绿，新增「改密码后仍可轮换密钥」回归测试。

## 2.3.x

### 2.3.1 · 2026-10-25

> **关于 2.3.0 的撤回**：2.3.0 把「化验的激素类型」做成参与校准的硬门槛，但升级前的旧记录没有该字段，导致所有历史化验在升级后被当成未确认，校准被静默关闭——曲线退化为未校准的模型值（实测 118 → 283 pg/mL）。2.3.1 修复该问题。

**校准与 PK**

- 升级时按单位自动补回旧记录类型（`pg/ml`、`pmol/l` → 雌二醇；`ng/dl`、`nmol/l` → 睾酮），规则与 2.2.2 一致；显式写着的类型不被覆盖，仅监测项保持无类型，重复执行不产生变化。

- 贴片：同一时刻记录的「取下」按零佩戴处理；修复短贴片把长贴片曲线剪成 0 的问题；混合定向 / 无向移除的配对在界面、内置引擎与 Transmtf 引擎之间一致。
